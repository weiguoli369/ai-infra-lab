02

矩形 Batch 的空位，也占空间

比较采用 dense padding 的常见批处理方式。PyTorch 本身也支持其他可变长实现，并非强制补齐。

A 有效 tokenB 有效 tokenPAD 空位

为什么合批通常更高效？

多个请求可在同一批矩阵运算中复用权重读取、摊薄 kernel 启动开销，尤其有利于带宽受限的 decode。

权重通常已驻留显存；计算时分块读取到片上缓存 / 寄存器。合批不意味着整份权重“只读一次”，分开运行也不保证耗时翻倍。

03

计算紧密打包，缓存按块寻址

Packing 处理变长输入；PagedAttention 管理 KV 的逻辑块到物理块映射；连续批处理决定每轮执行哪些请求。

① 本轮 Prefill 的 packed token buffer

每个请求独立分块；尾块空位不会跨请求自动拼满。

② 逻辑块 → 物理块 · 点击映射定位

选择一条映射，查看对应的物理块。

块号和摆放顺序为模拟。每个可视块表示一个跨层 KV 块束；真实实现通常按层管理 KV 张量。
