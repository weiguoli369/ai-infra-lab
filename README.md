# AI Infrastructure Lab

> Learning AI Infrastructure from GPU Fundamentals
> to Distributed Inference Systems.

## 🎯 About This Project

这是我的个人 AI Infrastructure 学习与实验项目。

目标是逐渐建立对以下领域的系统性理解：

- AI Model Architecture
- GPU Architecture & CUDA
- LLM Inference Engines
- Inference Optimization
- Distributed Computing
- AI Cluster & Scheduling
- Distributed Model Serving
- AI Platform Engineering

本项目不仅记录学习笔记，还包含可复现的实验、
性能测试、技术分析和实际工程项目。

## 🚀 Learning Philosophy

Learn → Experiment → Understand → Build

坚持以下原则：

1. 从真实技术问题开始。
2. 通过实验验证理论。
3. 深入理解系统底层原理。
4. 记录失败、问题与改进。
5. 持续构建自己的 AI Infra Lab。
